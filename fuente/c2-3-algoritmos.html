¿Receta o ejemplos?

No todos los problemas necesitan una red neuronal. Algunos se resuelven mejor con una receta escrita paso a paso. Tu misión: decidir qué herramienta usarías en cada caso.

Las dos herramientas
📜

Algoritmo clásico

Una persona escribe las reglas: «si pasa esto, haz aquello». Funciona cuando sabemos explicar exactamente cómo se resuelve el problema.

🧠

Red neuronal

Le damos muchos ejemplos con su respuesta y la red encuentra el patrón sola. Funciona cuando el patrón existe, pero nadie sabe escribirlo como reglas.

La regla práctica
¿Puedes escribir la receta?Si las reglas son claras, exactas y no cambian (impuestos, horarios, rutas), un algoritmo clásico es más barato, rápido y fácil de explicar.
¿Solo tienes ejemplos?Si sabes reconocer la respuesta pero no explicar cómo (una voz, una cara, una hoja enferma), una red neuronal puede aprender el patrón.
¿Hay datos suficientes?Sin muchos ejemplos de buena calidad, la red no aprende. Por eso el dato es tan importante (sección 11).
Para pensar

Piensa en un sistema de tu universidad o de tu trabajo. ¿Qué parte resolverías con reglas y qué parte, si alguna, con una red neuronal?
