Vigila el servidor con una red neuronal

Eres parte del equipo de sistemas de una universidad. Una red neuronal aprendió cómo es un día normal en el sistema de inscripciones. Tu trabajo: decidir qué tan sensible debe ser la alarma.

⏱ 7 minutosUn caso típico de Ingeniería de Sistemas
Primero, la idea
1📚

La red vio semanas de registros del servidor y aprendió cuántas peticiones por minuto son normales a cada hora.

2📏

Cada minuto compara lo que espera con lo que realmente pasa. La diferencia es el error de predicción.

3🚨

Si la diferencia es demasiado grande, avisa: puede ser una .

Aprender lo normalLa red no necesita ejemplos de cada ataque: le basta saber muy bien cómo es un día normal.
Todo es un equilibrioUna alarma muy sensible molesta con falsas alarmas; una poco sensible deja pasar problemas.
La red avisa, la persona decideEl ingeniero revisa cada alerta. Una venta de entradas no es un ataque, aunque el tráfico se parezca.
Para pensar

Si fueras el jefe de sistemas, ¿preferirías 5 falsas alarmas por día o un ataque cada mes sin detectar? No hay respuesta única: depende de lo que cuesta cada error.
